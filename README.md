# 우와한가 (WooWahanga)

우리 땅에서 정성껏 기른 농축산물을 소개하는 브랜드 웹사이트입니다.

## 실행 방법

빌드 과정 없이 `index.html`을 브라우저에서 열면 됩니다.

## 파일 구성

- `index.html` — 전체 페이지 구조와 한국어 콘텐츠
- `styles.css` — 반응형 디자인과 애니메이션
- `script.js` — 모바일 메뉴, 제품 필터, 문의 폼 안내
- `assets/woowahanga-hero.png` — 생성형 AI로 제작한 브랜드 대표 이미지

문의처와 이야기의 날짜·본문은 추후 실제 브랜드 정보로 교체할 임시 내용입니다.
